# Ameer Ahmed Alghamdi — Portfolio Website

A lightweight, responsive personal portfolio built with semantic HTML, CSS, and minimal JavaScript. No build step is required.

## Run locally

Open `index.html` directly, or use VS Code Live Server / any static server.

Example with Python:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.
